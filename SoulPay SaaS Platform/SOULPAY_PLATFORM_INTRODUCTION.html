SoulPay(소울페이)는 보유 도메인(soulpay.kr, soulpay.co.kr)과 Cloudflare 에지 인프라를 결합하여 결제 코어와 관리자 포털을 물리 분리함으로써 Zero Blast Radius와 99.99% 무중단 가용성을 실현합니다.

4대 독립 서브도메인 검토 Cloudflare 인프라 사양
01 · Domain Separation

서비스 성격별 4대 독립 서브도메인 명세

관리자 페이지나 정산 모듈의 릴리즈 작업이 기부자의 결제 엔진에 0.1%의 장애 영향도 주지 않도록 빌드 산출물과 배포 파이프라인을 완전 격리하였습니다.

pay.soulpay.kr SLA 99.99% Guaranteed

기부자 모바일 웹 결제 & 현장 키오스크 코어

성도 및 기부자를 위한 실시간 헌금·기부 전용 경량화 엔진입니다. 관리자 분석 도구나 통계 라이브러리를 완전히 배제하여 첫 화면 로딩 시간을 0.8초대로 단축하고, 생체인증 간편결제 및 카드 스캔을 지원합니다.

  • 번들 크기: 300KB 미만 초경량 최적화 (초고속 인입 보장)
  • 지원 수단: 카카오페이, 네이버페이, 토스페이, 신용카드, 카드 스캔 연동
  • 장애 격리: 단체 관리자 및 파트너 배포 작업과 물리적으로 무관 (Zero Blast Radius)
  • 연계 기능: 무회원 휴대폰 OTP 납부 내역 조회, 정기구독 헌금, 모바일 영수증
ops.soulpay.kr Zero Trust Protected

최고 시스템 운영 센터

본사 관리자 전용 관제 포털로 공공 인터넷에 직접 노출되지 않으며, Cloudflare Zero Trust로 완벽히 보호됩니다.

  • 보안 정책: 사내 공인 IP 및 관리자 2단계 이메일 핀코드 인증
  • 원장 관리: 다자간 정산 원장 (Multi-Party Ledger) 총괄
  • 가맹 심사: 단체 고유번호증 및 서류 검토 승인 데스크
admin.soulpay.kr Tenant Role Guard

단체 목회자 / 관리자 포털

개별 교회, 성당, 사찰의 재정 담당자와 목회자를 위한 통합 수납 관리 화면입니다. 당일 수납액 자동 마감 집계와 교인 명부 연계를 지원합니다.

  • 당일 마감 집계: PostgreSQL 기반 결측치 없는 일일 스냅샷 장부 생성
  • 종교별 맞춤 용어: 기독교(헌금/십일조), 천주교(봉헌/미사), 불교(보시/인등)
  • 교인 행정: 성도별 연간 기부 총액 및 홈택스 기부금 영수증 연동
partner.soulpay.kr Commission Ledger

총판 / 대리점 파트너 센터

전국 지사 및 영업 파트너를 위한 가맹 단체 유치 현황과 PG 결제 수수료 분배(Fee Sharing) 대시보드입니다.

  • 가맹 단체 등록: 영업 현장 태블릿을 통한 즉각적인 신규 단체 인입
  • 실시간 정산 내역: 결제 건당 요율 기반의 파트너 수수료 자동 배분
  • 권한 격리: 타 단체의 상세 교인 명부 및 내부 회계 데이터 접근 차단
02 · System Topology

글로벌 에지 인프라 라우팅 토폴로지

DNS 인입부터 에지 보안 필터링, 4개 독립 Pages 배포 산출물, 그리고 PostgreSQL 백엔드까지의 무중단 데이터 흐름입니다.

1. DNS Ingress soulpay.kr 네임서버 위임 및 서브도메인 CNAME 프록시 바인딩 Cloudflare Anycast DNS
2. Edge Security 결제 트래픽 DDoS 방어, Bot Fight Mode, ops Zero Trust IP 검증 WAF & Access Rules
3. Isolated Pages 4개 독립 빌드 산출물(dist/pay, dist/admin 등) 개별 호스팅 Cloudflare Pages (ICN PoP)
4. Ledger Engine Supabase Edge Functions 검증 및 PostgreSQL 다자간 정산 원장 기록 Row Level Security
03 · Technical Evaluation

인프라 아키텍처 비교 명세

기존 단일 모놀리식 구조 대비 Cloudflare 통합 기반 분리 아키텍처의 엔지니어링 팩트 비교입니다.

검토 항목 기존 단일 모놀리식 (Vercel) SoulPay 확정 아키텍처 (Cloudflare Pages)
장애 전파 범위 (Blast Radius) 관리자 UI 수정 시 결제 엔진 전체 재배포 4대 서브도메인 100% 완전 격리 (결제 위험도 0%)
트래픽 및 대역폭 비용 성탄절/주일 트래픽 몰림 시 대역폭 초과 과금 리스크 무제한 대역폭 & 무제한 요청수 (비용 폭탄 0원)
결제 유입 경로 보안 기본적인 SSL만 제공 (엔터프라이즈 WAF 고가) 글로벌 1위 엔터프라이즈 WAF & DDoS 완화 기본 탑재
운영 센터 (ops) 보호 IP 화이트리스트 불가 (인터넷 전체에 화면 노출) Cloudflare Zero Trust 연동 (사내 IP / 이메일 OTP 통제)
비상 롤백 전파 시간 전체 재빌드 및 DNS 전파 대기 (10~30분 소요) Cloudflare 프록시 CNAME 즉각 전환 (1분 이내 롤백)

디지털 헌금 문화의 신뢰할 수 있는 표준

물리적으로 완전 분리된 4대 도메인 인프라를 바탕으로 무중단 결제와 투명한 회계 정산을 지원합니다.
