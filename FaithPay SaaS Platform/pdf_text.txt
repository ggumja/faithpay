1. 공통 
⚫ 프로토콜 : HTTPS/HTTP 
⚫ HTTP Method : POST 
⚫ URL  
테스트 http://dev3.nanopay.co.kr 
운영 https://pay.nanopay.co.kr 
⚫ Headers 
Header Value 
Content-Type application/json 
CharSet UTF-8 
API_KEY *필수 
⚫ 승인 결과는 요청시 전달 된 receiveUrl로 json 데이터 전송 
⚫ 테스트 환경에서는 가상계좌 입금통보 불가 
- 테스트 필요시 담당자에게 요청 
⚫ 가상계좌 결제 요청 후 입금 완료 되면 등록 된 noti URL로 josn 데이터 전송 
- noti URL은 담당자를 통해 등록 필수
