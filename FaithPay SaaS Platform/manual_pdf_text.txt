1. 공통 
⚫ 프로토콜 : HTTPS/HTTP 
⚫ HTTP Method : POST 
⚫ URL  
테스트 http://dev3.nanopay.co.kr 
운영 https://pay.nanopay.co.kr 
⚫ Headers 
Header Value 
Content-Type application/json 
CharSet UTF-8 
API_KEY *필수 
 
⚫ 암호화 방식 : AES-256-CBC, PKCS7 
 
 
2. 결제요청 
⚫ URL : /api/payment/approval.io 
⚫ 요청 
 
필드 필드명 타입 필수 비고 
ver 버전 String △  
loginId 사용자 ID String O  
shopcode 가맹점코드 String O  
payMethod 결제방법 String O Q : QR결제 
payType 결제(정산)타입 String △  
orderName 주문자명 String O  
orderTel 주문자 전화번호 String O  
orderEmail 주문자 이메일 String   
goodsName 상품명 String O

compOrderNo 업체주문번호 String   
compOrderMem 업체주문자정보 String   
encData 카드정보 암호화 String O 카드정보 json 전체 AES 암호화
